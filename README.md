# AI Challenge Banking - PSBxMAI

-----------------------
## Описание

Проект представляет собой интеллектуальную систему для анализа и обработки входящей корреспонденции с использованием искусственного интеллекта. Система автоматизирует рутинные процессы обработки документов, обеспечивая высокую точность и скорость отклика.

### Поддерживаемые возможности

* **Анализ входящей корреспонденции**: автоматическое извлечение и структурирование данных из писем.
* **Определение критичных параметров обработки**: выявление приоритетных и важных запросов для первоочередного внимания.
* **Генерация адаптивных ответов**: автоматическое создание релевантных ответов на основе содержания запросов и контекста.
* **Интеллектуальная маршрутизация и согласование**: автоматическое распределение задач и согласование документов между ответственными лицами.
* **Интеллектуальная система уведомлений**: информирование пользователей о статусах и результатах обработки через email и внутренние оповещения.

-----------------------
## Стек технологий

* **Backend**: Python, FastAPI.
* **Базы данных**: SQLAlchemy (ORM), AsyncPG (асинхронный драйвер PostgreSQL).
* **Сервер приложений**: Uvicorn.
* **Обработка данных**: python-multipart.

## Запуск проекта

### Локальная установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   ```
2. Установите необходимые зависимости из файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер разработки:
   ```bash
   uvicorn backend.main:app --reload
   ```
   Сервер будет доступен по адресу `http://localhost:8000`. Интерактивная документация (Swagger UI) доступна по адресу `http://localhost:8000/docs`.

-----------------------
## Основные эндпоинты (API)

* `GET /` - Проверка доступности сервиса. Возвращает приветственное сообщение.
* `GET /hello/{name}` - Тестовый эндпоинт, возвращающий персонализированное приветствие.
* `POST /message` - Прием нового сообщения для обработки. Возвращает статус получения.

-----------------------
## Алгоритм работы системы

1. **Регистрация**: Пользователь проходит процесс регистрации и авторизации в системе.
2. **Импорт данных**: Входящее письмо или документ импортируется в систему для дальнейшего анализа.
3. **Анализ ИИ**: AI-модель анализирует содержание текста, классифицирует его, выделяет ключевые темы и определяет критичные параметры обработки.
4. **Генерация ответа**: Система автоматически формирует адаптивный ответ с учетом извлеченных параметров и определенных тематик.
5. **Сохранение**: Исходное письмо, результаты анализа и сгенерированный ответ сохраняются в базу данных.
6. **Уведомление**: Система рассылает соответствующие оповещения ответственным лицам в интерфейсе системы или по электронной почте.
